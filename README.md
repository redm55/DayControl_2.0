===Таймер до Нового Года===

Таймер идёт до 31.12.[текущего года] (до 23:59 по времени Вашего региона)
После конца отсчета автоматически обновляется до следующего Нового Года.

Старую версию Вы можете увидеть на https://artskorn.github.io/DayControl/
Новая версия проживает тут https://redm55.github.io/DayControl_2.0/
